# Prompt_AI
Prompt to Picture – Text-to-Image Generator

Project Review

Prompt to Picture is an AI-based Text-to-Image Generator. It converts a text prompt given by the user into an AI-generated image using the SD-Turbo Stable Diffusion model.

The project is developed using Python and Streamlit and runs on a Google Colab GPU. It does not require an API key.

Features

- Converts text into images.
- Simple Streamlit interface.
- Uses SD-Turbo Stable Diffusion model.
- Supports custom text prompts.
- Adjustable image generation steps.
- Seed option for generating repeatable results.
- Download generated images.
- Maintains image history during the session.
- Uses GPU for faster generation.

How to Run the Project

1. Open the ".ipynb" file in Google Colab.
2. Select Runtime → Change runtime type → T4 GPU.
3. Run all the cells in order.
4. Install the required libraries.
5. Check that the GPU is detected.
6. Start the Streamlit application.
7. Open the generated Cloudflare URL.
8. Enter a text prompt.
9. Click Generate.
10. The generated image will be displayed.

Example Prompt

"A cozy South Indian filter coffee stall at dawn, steam rising from a tumbler, warm golden light, cinematic photography."
